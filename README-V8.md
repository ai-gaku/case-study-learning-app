# 事例検討型Web教材 Ver.8（学習導線とフィードバック）

## 更新するファイル
GitHubの同じ場所にある `app.js`, `index.html`, `style.css`, `cases.js` の4ファイルを置き換えます。`config.js` は変更しません。SupabaseのSQLは不要です。Ver.7/Ver.6のコード照合・保存・匿名認証を継承しています。

## 変更点
- 評価観点を文章で明示し、ヒント利用の非減点を別段落に
- Supabaseなど学生に不要な技術用語を画面文言から削除
- 表示済みヒントは`details`で開閉でき、ボタンの重複反応を改善
- 最終回答時、初回回答・閲覧済み観察情報・閲覧済みヒントを必要に応じて参照
- 別事例で応用するのは「対応のコピー」ではなく「考える手順」だと明示
- 振り返り時、初回・最終・別事例の回答を参照
- 振り返り後、教員執筆の事例解説と操作履歴に基づく事実の表示
- 最後に次回の学習目標を5選択肢から1つ選択。`learning_events` の `reflection` イベントの `payload.next_focus` と `payload.next_focus_label` に保存

## 動作確認
架空の登録済み参加コードで操作し、振り返り→解説→次の目標選択→完了の順に進みます。Supabaseの `learning_events` に `reflection` 行と `next_focus` が1つ記録されるか確認します。

## 研究上・安全上の制限
学生回答そのものを自動評価しません。学習過程のメッセージはボタンやヒント閲覧の事実のみで、学習の改善を保証しません。既存のブラウザ保存方式は端末間の再開に非対応、通信失敗時の自動再送機能もありません。まだ架空データで検証してください。
