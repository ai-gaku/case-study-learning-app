# 事例検討型Web教材 Ver.10（UI改善）

## 目的
Ver.9の学習内容・参加コードのサーバー照合・Supabase記録形式を維持しながら、学習体験の区切りを明確化する。

## 変更
- スタート画面に参加コード設定、事例選択、事例紹介、開始ボタンを集約。
- 学習中は事例本文の閲覧欄、6段階のステップ表示、進捗バーを表示。
- 完了時に控えめな完了マークと、事例選択に戻るボタンを表示。
- スマートフォン向けの余白・背景・カード・ステップを調整。
- 音声・強いアニメーションは未実装。動きを減らす設定を尊重。

## GitHubで置き換えるファイル
- app.js
- index.html
- style.css

cases.js はVer.9のものをそのまま使えます。config.jsは接続情報入りの既存ファイルを必ず維持してください。SupabaseのSQL変更は不要です。

## 手順
1. ZIPを解凍する。
2. 既存のGitHubリポジトリで上記3ファイルを置き換える。
3. コミット後Vercelの最新デプロイがReadyとなったらページを再読み込みする。
4. 架空の登録済み参加コードを設定し、事例を選んで開始する。
5. 事例本文を確認しながら、6段階の進捗表示・ヒント・解説・目標選択・別事例を一通り試す。
6. 完了画面から事例選択に戻り、もう一つの事例に取り組めることを確認する。
7. Supabaseのlearning_eventsに`start`, `draft`, `final`, `transfer`, `reflection`などの記録があることを確認する。

## 継続途中の記録について
Ver.10は保存キーを `case-study-active-v10` に変更しています。Ver.9以前の途中保存からは再開しません。Ver.9までのSupabase上の学習ログは消えません。Ver.10で初回アクセス時には、学習を開始するまではstartログは作りません。

## 利用上の注意
- 教員による架空データでの検証用です。個人情報・実学生の回答を入力する前に研究倫理・情報セキュリティ等の手続きを確認してください。
- 参加コードは本人確認ではありません。共用端末や端末変更への対応は今後の検討課題です。
- 効果音はまだ追加していません。今後追加する場合も初期OFF・ON/OFF可能、音なしでも情報が伝わる仕様を推奨します。
- 既存の記録送信は確定時の処理です。失敗時の確実な再送は未実装です。
