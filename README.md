# 事例検討型Web教材 Ver.10.1 — 操作と解説の改善

Ver.10をベースとする差分更新です。既存の参加コード照合、回答の一時保存、Supabaseへのイベント記録は維持します。

## 今回の修正
1. 学習段階・終了画面へ切り替わるたびに、ページ上部へスクロール位置を戻す（初回描画時と画面切替時）。
2. STEP 2 の説明を「以下の追加情報を確認してください。」に変更。
3. ヒントはタイトルの開閉操作１回で表示／非表示を切り替える。**初回にヒントを開いた時だけ**`hint_open`を記録する。閉じたり開き直したりしても重複記録しない。入力中の最終回答は保持する。
4. フィードバックは「考え方のポイント」→「詳しく書いた場合の回答例」→「理由・学習過程」に変更。回答例と同程度の文字数を書く必要はないことを明示。

## 更新方法
GitHubの **app.js だけ** をこのフォルダの同名ファイルで置き換え、コミットしてください。Vercel の最新デプロイが Ready になったら確認します。

- `config.js`は置き換えません（同梱していません）。
- `cases.js`、`style.css`、`index.html`は変更しません。
- SQL Editorでの操作は不要です。
- Ver.10 と同じ途中保存キーを使うため、Ver.10 の保存済みの途中回答から原則再開できます。

## 動作確認（架空データ）
1. 下までスクロールして「次へ」を押す→次画面の最上部が表示されるか。
2. STEP 2 の指定文言を確認。
3. STEP 3 で、未利用のヒントの見出しを1回押す→内容がその場で開く。もう1回押す→閉じる。再度開いても回答文が消えない。
4. Supabase の `hint_open` がそのヒントにつき1回のみ記録されるか。
5. STEP 4 のフィードバックで、観点が先に提示され、詳述例であることが明示されるか。

## 注意
教員による試作検証向けです。実学生による利用には研究倫理・個人情報・情報管理等の確認が必要です。通信障害時の確実な再送はまだ未実装です。
